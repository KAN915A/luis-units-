## The shared scenario used in the worked examples

**GreenLeaf Cafés** — a small UK café chain (12 branches). They want an **online ordering + pre-pay system** so customers can order via a web app and collect in-store. Budget **£40,000**. Deadline: **live by 1 December** (Christmas rush). Team: 1 project manager, 2 developers, 1 UX designer, 1 tester. Sponsor: the Operations Director. Client contact: the IT Manager.

Every worked example on the pages below references this same scenario so the evidence chains together (business case → PID → Gantt → checkpoint report → closure email → post-project review).
